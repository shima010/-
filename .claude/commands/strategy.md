# 戦略企画部 — ルーティングガイド

## 部門概要

戦略企画部は、プロジェクト全体の方向性を決定し、各部門への指示を統括する司令塔です。
市場分析、事業計画策定、競合調査、KPI設定など、上流工程のタスクを担当します。
コンサルティング案件の初期フェーズや、新規サービス立案時に最も活躍する部門です。

## タスクルーティングテーブル

| タスク | 担当エージェント | 説明 |
|--------|------------------|------|
| 市場調査・競合分析 | リサーチエージェント | 業界動向、競合他社の戦略、市場規模の調査を実施 |
| 事業計画書の作成 | プランニングエージェント | 中長期の事業計画、ロードマップの策定 |
| KPI設計・目標設定 | アナリティクスエージェント | 数値目標の設定、KPIツリーの構築 |
| SWOT分析・3C分析 | フレームワークエージェント | 戦略フレームワークを用いた現状分析 |
| クライアント向け戦略提案 | コンサルエージェント | 課題整理から施策提案までの一連の流れを作成 |
| 予算配分・リソース計画 | プランニングエージェント | 各部門へのリソース配分、投資対効果の検討 |
| 四半期レビュー資料作成 | レポートエージェント | 実績と目標の比較、次期戦略の方向性をまとめる |

## 使用例

### 例1: 新規クライアントの市場分析を依頼する場合
```
/strategy 「飲食業界のEC展開」について市場調査を実施してください。競合3社の比較と市場規模の推定を含めてください。
```

### 例2: 事業計画の策定
```
/strategy 来期の副業コンサルティング事業の事業計画を作成してください。売上目標、主要施策、スケジュールを含めてください。
```

### 例3: クライアント向け戦略提案書の作成
```
/strategy クライアントA社向けに、SNSマーケティング戦略の提案書を作成してください。3C分析を含めてください。
```

## 注意事項

- 戦略企画部のタスクは他部門への影響が大きいため、必ず完了後に関連部門へ共有すること
- クライアント向け資料は、ブランドガイドに準拠したトーンで作成すること
- 数値データを含む分析は、出典を明記すること
- 機密性の高い情報を扱う場合は、セキュリティ・プライバシーガイドを参照すること
- 大型案件の場合は、管理部と連携して予算・スケジュールを確認すること
