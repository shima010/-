# 営業部 — ルーティングガイド

## 部門概要

営業部は、見込み客の獲得からクロージング、既存顧客のフォローアップまでを担当する部門です。
コンサルティング案件の受注活動、提案書・見積書の作成、顧客関係管理（CRM）を統括します。
副業プロジェクトの収益を直接支える重要な部門です。

## タスクルーティングテーブル

| タスク | 担当エージェント | 説明 |
|--------|------------------|------|
| 提案書の作成 | プロポーザルエージェント | クライアント向け提案書のドラフト作成、構成検討 |
| 見積書の作成 | 見積エージェント | サービス内容に基づく見積書の作成、価格設定の検討 |
| 営業メールの作成 | アウトリーチエージェント | 初回アプローチ、フォローアップ、お礼メールの作成 |
| 顧客リスト管理 | CRMエージェント | 見込み客・既存顧客の情報整理、ステータス更新 |
| 営業戦略の立案 | セールスストラテジーエージェント | ターゲット選定、アプローチ方法、営業プロセスの設計 |
| 競合比較資料の作成 | リサーチエージェント | 自社サービスと競合の比較表、差別化ポイントの整理 |
| 契約書ドラフト作成 | コントラクトエージェント | 業務委託契約書、NDA等のドラフト作成 |

## 使用例

### 例1: 提案書の作成
```
/sales C社向けにSNSマーケティング支援の提案書を作成してください。月額30万円のプランで、サービス内容と期待効果を含めてください。
```

### 例2: 見積書の作成
```
/sales ウェブサイトリニューアルのコンサルティング見積書を作成してください。3ヶ月プロジェクトで、フェーズごとの費用内訳を含めてください。
```

### 例3: フォローアップメール
```
/sales 先週面談したD社担当者へのフォローアップメールを作成してください。提案内容のサマリーと次回打合せの日程調整を含めてください。
```

## 注意事項

- 見積書の金額設定は財務管理ガイドの料金テーブルを参照すること
- 提案書はブランドガイドに準拠したデザイン・トーンで作成すること
- 契約書ドラフトは法的な助言に代わるものではないため、必要に応じて専門家に確認すること
- 顧客の個人情報・企業機密情報はセキュリティガイドに従って管理すること
- 大型案件（50万円以上）は戦略企画部と連携して進めること
- 受注後は管理部に連絡し、請求・経理処理の準備を進めること
