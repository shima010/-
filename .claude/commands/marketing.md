# マーケティング部 — ルーティングガイド

## 部門概要

マーケティング部は、集客・認知拡大・リード獲得を担当する部門です。
SNS運用、広告運用、SEO対策、メールマーケティングなど、デジタルマーケティング全般を統括します。
コンサルティング案件のマーケティング支援や、自社の集客活動の両方を担います。

## タスクルーティングテーブル

| タスク | 担当エージェント | 説明 |
|--------|------------------|------|
| SNS投稿の企画・作成 | SNSエージェント | Twitter、Instagram、LinkedIn等の投稿文作成・スケジュール管理 |
| 広告コピー・クリエイティブ作成 | 広告エージェント | Google広告、SNS広告のコピーライティングと配信設計 |
| SEO記事の企画・キーワード選定 | SEOエージェント | 検索キーワード調査、記事構成案の作成、メタ情報の最適化 |
| メールマーケティング | メールエージェント | メルマガの企画、配信文の作成、配信リスト管理 |
| アクセス解析・レポート作成 | アナリティクスエージェント | GA4等のデータ分析、月次レポートの作成 |
| コンテンツカレンダー管理 | カレンダーエージェント | 月間・週間の投稿計画の策定と進捗管理 |
| キャンペーン企画 | キャンペーンエージェント | 季節・イベントに合わせたプロモーション企画 |

## 使用例

### 例1: SNS投稿を作成する場合
```
/marketing 今週のLinkedIn投稿を3本作成してください。テーマは「中小企業のDX推進」です。
```

### 例2: SEOキーワード調査
```
/marketing 「コンサルティング 副業」関連のSEOキーワードを調査し、記事構成案を3本分作成してください。
```

### 例3: 月次マーケティングレポート
```
/marketing 3月のSNS運用レポートを作成してください。フォロワー数推移、エンゲージメント率、上位投稿の分析を含めてください。
```

## 注意事項

- SNS投稿はブランドガイドのトーン・マナーに必ず準拠すること
- 広告出稿前に予算を管理部に確認すること
- クライアント案件のSNS運用は、クライアントの承認フローを確認すること
- KPI設定はマーケティングプレイブックの基準を参照すること
- 個人情報を含むリストの取扱いはセキュリティガイドに従うこと
- コンテンツの二次利用やクロスポストの際は品質管理部のレビューを受けること
