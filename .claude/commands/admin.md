# 管理部 — ルーティングガイド

## 部門概要

管理部は、経理・会計処理、スケジュール管理、事務手続き全般を担当する部門です。
請求書の発行、経費精算、確定申告準備、契約管理など、バックオフィス業務を統括します。
副業プロジェクトの運営基盤を支える縁の下の力持ちです。

## タスクルーティングテーブル

| タスク | 担当エージェント | 説明 |
|--------|------------------|------|
| 請求書の作成・発行 | 請求エージェント | クライアント向け請求書の作成、発行管理、入金確認 |
| 経費精算・記帳 | 経理エージェント | 経費の分類・記帳、領収書の整理、帳簿管理 |
| 確定申告準備 | 税務エージェント | 年間収支の集計、必要書類の整理、申告書のドラフト |
| スケジュール管理 | スケジューラーエージェント | 会議設定、締切管理、カレンダー調整 |
| 契約書管理 | 契約管理エージェント | 契約書の保管、更新時期のリマインド、台帳管理 |
| 月次収支レポート | レポートエージェント | 月間の売上・経費・利益のレポート作成 |
| 各種届出・手続き | 事務エージェント | 行政手続き、届出書類の準備、各種申請対応 |

## 使用例

### 例1: 請求書の作成
```
/admin E社向けに3月分のコンサルティング費用の請求書を作成してください。金額は33万円（税込）、支払期限は翌月末です。
```

### 例2: 月次収支レポート
```
/admin 2月の収支レポートを作成してください。売上、経費（項目別）、営業利益を含めてください。
```

### 例3: 経費の記帳
```
/admin 以下の経費を記帳してください。3月15日：書籍購入3,300円、3月18日：クラウドサービス月額2,200円、3月20日：交通費1,500円。
```

## 注意事項

- 請求書は財務管理ガイドのフォーマットに従うこと
- 経費処理は発生から1週間以内に記帳すること
- 確定申告関連のタスクは税理士への相談が必要な場合がある点に留意すること
- 金額に関わるデータは必ずダブルチェックを行うこと
- 個人情報・金融情報を含む書類はセキュリティガイドに従って管理すること
- 契約更新のリマインドは期限の1ヶ月前に設定すること
