# コンテンツ制作部 — ルーティングガイド

## 部門概要

コンテンツ制作部は、あらゆる文章・資料・クリエイティブの制作を担当する部門です。
ブログ記事、提案資料、ホワイトペーパー、プレゼン資料、コピーライティングなど、
テキストベースの成果物を高品質に仕上げることがミッションです。

## タスクルーティングテーブル

| タスク | 担当エージェント | 説明 |
|--------|------------------|------|
| ブログ記事の執筆 | ライティングエージェント | SEO対応のブログ記事、コラム、ノウハウ記事の執筆 |
| プレゼン資料の構成・作成 | ドキュメントエージェント | PowerPoint/Googleスライド向けの構成案と原稿作成 |
| ホワイトペーパー作成 | リサーチライターエージェント | 調査データに基づく専門的なレポート・資料の執筆 |
| コピーライティング | コピーエージェント | キャッチコピー、タグライン、広告文の作成 |
| メール文面の作成 | コミュニケーションエージェント | 営業メール、フォローアップメール、案内文の作成 |
| 翻訳・ローカライズ | 翻訳エージェント | 日英翻訳、英日翻訳、文化的なローカライズ対応 |
| 校正・リライト | エディターエージェント | 既存文章の校正、読みやすさの改善、トーン調整 |

## 使用例

### 例1: ブログ記事の執筆
```
/content 「副業コンサルタントが教える営業の基本」というテーマで、2000文字程度のブログ記事を執筆してください。
```

### 例2: プレゼン資料の構成案
```
/content クライアントB社向けの初回提案プレゼン資料の構成案を作成してください。10スライド程度で、課題整理から解決策まで含めてください。
```

### 例3: 営業メールの作成
```
/content 新規見込み客へのアプローチメールを作成してください。コンサルティングサービスの紹介と面談の打診を含めてください。
```

## 注意事項

- すべての成果物はブランドガイドのトーンに合わせること
- ブログ記事はSEOキーワードをマーケティング部と連携して決定すること
- クライアント向け資料は、提出前に品質管理部のレビューを必ず受けること
- 翻訳タスクは専門用語リストを事前に確認すること
- コピーライティングは複数案を提示し、比較検討できるようにすること
- 著作権・引用ルールを遵守し、出典を明記すること
