# 品質管理部 — ルーティングガイド

## 部門概要

品質管理部は、全部門の成果物の品質を保証するゲートキーパーの役割を担う部門です。
文章の校正、資料のレビュー、ファクトチェック、ブランド準拠確認など、
成果物がクライアントや外部に出る前の最終チェックを行います。

## タスクルーティングテーブル

| タスク | 担当エージェント | 説明 |
|--------|------------------|------|
| 文章校正・誤字脱字チェック | 校正エージェント | 文法、誤字脱字、表記ゆれの修正 |
| ブランド準拠チェック | ブランドエージェント | トーン、表現、デザインがブランドガイドに準拠しているか確認 |
| ファクトチェック | ファクトチェックエージェント | 数値データ、統計情報、引用元の正確性を検証 |
| 提案書・見積書レビュー | ドキュメントレビューエージェント | 構成、論理展開、説得力の観点からレビュー |
| SEOコンテンツ品質チェック | SEOレビューエージェント | キーワード密度、メタ情報、読みやすさの確認 |
| 最終納品前チェック | 納品チェックエージェント | 全項目の最終確認、チェックリストに基づく網羅的な検証 |
| フィードバックレポート作成 | フィードバックエージェント | レビュー結果のまとめ、改善提案の文書化 |

## 使用例

### 例1: ブログ記事の校正
```
/quality 以下のブログ記事を校正してください。誤字脱字、文法ミス、表記ゆれをチェックし、修正案を提示してください。
```

### 例2: 提案書のレビュー
```
/quality F社向け提案書をレビューしてください。論理構成、説得力、ブランドトーンの観点からフィードバックをお願いします。
```

### 例3: 納品前の最終チェック
```
/quality G社に納品予定のマーケティングレポートを最終チェックしてください。品質基準のチェックリストに基づいて確認してください。
```

## 注意事項

- クライアント向け成果物は必ず品質管理部のレビューを通してから納品すること
- レビューは品質基準ガイドラインのチェックリストに基づいて実施すること
- 緊急案件でもレビュープロセスを省略しないこと
- フィードバックは具体的かつ建設的な内容にすること
- 修正依頼は優先度をつけて明確に伝えること
- 繰り返し発生する品質課題はガイドラインの改善に反映すること
