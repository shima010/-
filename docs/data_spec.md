# 入力データ仕様

1つのフォルダに次の5ファイルを置きます。形式は CSV(UTF-8 または Shift_JIS)か xlsx です。
前年比を出すため、**対象月を含めて最低13か月分、推奨は25か月分**を入れてください。

| ファイル名 | 内容 | 主な取得元(想定) |
|---|---|---|
| `company_pl.csv` | 全社損益(実績・予算) | 会計システム(GRANDIT)の月次試算表、予算管理表 |
| `company_bs.csv` | 全社貸借(月末残高) | 会計システムの月次試算表 |
| `store_monthly.csv` | 店舗別の売上・損益・客数・在庫 | 部門別損益、POS、在庫システム |
| `sales_category.csv` | 店舗×部門×チャネルの売上・粗利 | 販売管理(POS・EC) |
| `lesson_members.csv` | 店舗×コースの教室会員の増減と月謝売上 | 教室管理システム |

年月は `2026-10`、`2026/10`、`202610`、`2026年10月` のいずれでも読み込めます。金額はすべて**円単位**です。

## 1. company_pl.csv(縦持ち)

| 列 | 内容 |
|---|---|
| 年月 | 対象月 |
| 科目 | 下記の9科目 |
| 実績 | 円 |
| 予算 | 円(予算がない科目は実績と同額または0) |

科目: `売上高` `売上原価` `人件費` `地代家賃` `広告宣伝費` `減価償却費` `その他販管費` `営業外収益` `営業外費用`

売上総利益・販管費計・営業利益・経常利益・EBITDA はツール側で計算します。
上記以外の販管費科目(水道光熱費、支払手数料など)は `その他販管費` に合算してください。
講師報酬を売上原価に計上しているか販管費に計上しているかで粗利率の意味が変わるため、**毎月同じ基準で集計**してください。

## 2. company_bs.csv(縦持ち)

| 列 | 内容 |
|---|---|
| 年月 | 対象月 |
| 科目 | 下記の10科目 |
| 残高 | 月末残高(円) |

科目: `現金預金` `売掛金` `商品` `その他流動資産` `固定資産` `買掛金` `前受金` `その他流動負債` `有利子負債` `純資産`

- `売掛金` にはクレジット・ショッピングローンの未収分を含めます。
- `前受金` は教室月謝の前受分を想定しています(商品券・予約金を含める場合は、その旨をメモしておいてください)。
- 貸借が一致しない場合はデータ品質の注意点として表示されます。

## 3. store_monthly.csv(店舗×月)

| 列 | 内容 |
|---|---|
| 年月 | |
| 店舗コード | 他ファイルと共通のコード |
| 店舗名 | |
| エリア | 集計単位(ブロック・地域) |
| 業態 | `SC` / `路面` / `EC` など。`EC` は店舗比較から除外 |
| 開店年月 | 既存店(開店後13か月以上)の判定に使用 |
| 売上高 | 物販+教室の合計(円) |
| 売上予算 | 円 |
| 売上総利益 | 円 |
| 人件費 | 店舗に直接かかる人件費(円) |
| 地代家賃 | 円 |
| その他経費 | 店舗の直接経費(円)。本部費の配賦は含めない |
| 客数 | 物販のレシート枚数 |
| 在庫高 | 月末在庫(原価、円) |

店舗利益 = 売上総利益 − 人件費 − 地代家賃 − その他経費(本部費配賦前の店舗貢献利益)として計算します。

## 4. sales_category.csv(店舗×部門×チャネル×月)

| 列 | 内容 |
|---|---|
| 年月 | |
| 店舗コード | |
| 部門 | 例: ピアノ・電子ピアノ、ギター・ベース、管楽器、ドラム・打楽器、DTM・音響機器、弦楽器、アクセサリ・楽譜、修理・サービス、**音楽教室** |
| チャネル | `店舗` / `EC` |
| 売上高 | 円 |
| 売上総利益 | 円 |

- 教室の月謝売上は部門 `音楽教室` として入れてください(物販と教室を分けて分析するため)。
- 店舗ごとの部門合計は store_monthly の売上高と一致する必要があります(不一致はデータ品質で検知)。

## 5. lesson_members.csv(店舗×コース×月)

| 列 | 内容 |
|---|---|
| 年月 | |
| 店舗コード | |
| コース | 例: ピアノ、ギター・ベース、ボーカル、ドラム、管楽器、キッズ・リトミック、DTM・その他 |
| 月初会員数 | 前月の月末会員数と一致させる |
| 入会数 | |
| 退会数 | |
| 月末会員数 | 月初 + 入会 − 退会 |
| 体験レッスン数 | 入会率(体験→入会)の算出に使用 |
| 月謝売上 | 円 |

休会者を会員に含めるかどうかは会社の定義に合わせ、**毎月同じ基準**で集計してください。
コース変更(ピアノ→ボーカル等)は「旧コースの退会+新コースの入会」で計上すると退会率が過大になるため、可能なら別集計してください。

## GRANDIT などからの取り込みのコツ

- 試算表の出力は横持ち(科目×月)のことが多いため、Excel の「ピボット解除」や Power Query で縦持ちに変換してください。Claude Code に「この試算表を company_pl.csv の形式に変換して」と依頼することもできます。
- 店舗コードは5ファイルで同じ体系にそろえてください。閉店・統合した店舗は、比較期間中はコードを残すと前年比が正しく出ます。
