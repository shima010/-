# M&Aプロセスガイドライン

## 目的
島村楽器株式会社のM&A活動を体系的かつ効率的に進めるための標準プロセスを定める。

## 適用範囲
M&A推進部が主導する全てのM&A案件（買収・合併・事業譲受・資本提携を含む）。

## M&A戦略フレームワーク

### 投資テーマ（優先順位順）
1. **楽器小売の地域拡大** - 未進出エリアへの店舗網拡大
2. **音楽教室の拡充** - 教室運営ノウハウ・講師人材の獲得
3. **EC・デジタル強化** - オンライン販売・デジタルサービスの強化
4. **周辺事業への拡張** - 音楽関連サービス（イベント、録音、配信等）
5. **サプライチェーン強化** - 楽器メーカー・卸売との垂直統合

### ターゲット基準
| 項目 | 基準 |
|---|---|
| 売上規模 | 1億円〜100億円 |
| 業種 | 楽器・音楽・教育関連 |
| 地域 | 日本国内（将来的にはアジア） |
| 収益性 | EBITDA黒字（ターンアラウンド案件は例外的に検討） |
| 企業文化 | 音楽への情熱を共有できること |

## 標準プロセス（6フェーズ）

### Phase 1: ソーシング（案件発掘）- 目安2〜4週間
- ロングリスト作成（20〜50社）
- 初期スクリーニング（戦略適合性・規模・収益性）
- ショートリスト作成（5〜10社）
- **成果物**: ターゲットリスト、初期評価メモ

### Phase 2: アプローチ - 目安2〜4週間
- ターゲットへの初期接触（直接 or アドバイザー経由）
- NDA締結
- 初期情報交換
- **成果物**: NDA、初期情報メモ

### Phase 3: デューデリジェンス - 目安4〜8週間
- 財務DD（CFOエージェントと連携）
- 事業DD（DDアナリストが主導）
- 法務DD（リスク管理部と連携）
- IT DD（CIOエージェントと連携）
- 人事DD
- **成果物**: DD報告書、リスクサマリー

### Phase 4: バリュエーション・交渉 - 目安4〜6週間
- 企業価値評価（DCF法、マルチプル法、純資産法）
- 買収価格レンジの設定
- LOI（意向表明書）の提出
- 条件交渉
- **成果物**: バリュエーションレポート、LOI

### Phase 5: 契約・クロージング - 目安4〜8週間
- SPA（株式譲渡契約書）の交渉・締結
- 各種許認可の取得
- クロージング条件の充足
- 資金決済
- **成果物**: SPA、クロージングメモ

### Phase 6: PMI（統合） - 目安6〜12ヶ月
- Day 1対応（初日の体制移行）
- 100日プラン（短期統合施策）
- 中期統合計画（システム統合、組織統合、文化統合）
- シナジー実現のモニタリング
- **成果物**: PMI計画書、進捗報告書

## バリュエーション基準

| 手法 | 用途 | 備考 |
|---|---|---|
| DCF法 | メイン手法 | WACC: 8〜10%、永続成長率: 0〜1% |
| EV/EBITDA | クロスチェック | 目安: 6〜10倍（業種・成長性で調整） |
| EV/売上高 | 赤字企業の参考 | 目安: 0.5〜2.0倍 |
| 純資産法 | フロア価格 | 時価純資産ベース |

## 意思決定権限

| 案件規模 | 決裁者 |
|---|---|
| 〜1億円 | 統括部長 |
| 1億円〜10億円 | 取締役会 |
| 10億円超 | 取締役会 + 株主総会（必要に応じて） |

## リスク管理
- 全案件でリスク管理部のレビューを受ける
- Red Flag発見時は案件を一時停止し、対応策を協議
- 表明保証保険の付保を検討
- PMI失敗リスクに対する撤退基準を事前設定
