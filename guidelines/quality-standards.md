# 品質基準

## 目的

すべての成果物が一定以上の品質を保つための基準とレビュープロセスを定義する。

---

## 品質の5つの柱

1. **正確性**: 事実・データに誤りがないこと
2. **明確性**: 読み手にとってわかりやすいこと
3. **一貫性**: トーン・フォーマット・用語が統一されていること
4. **完全性**: 必要な情報が漏れなく含まれていること
5. **適時性**: 期限内に適切なタイミングで提供されること

---

## レビュープロセス

### フロー
1. **作成者が自己チェック** → チェックリストに基づく
2. **品質管理部にレビュー依頼** → レビュアーが詳細チェック
3. **フィードバック返却** → 修正点を重要度付きで報告
4. **修正・再提出** → 作成者が修正
5. **再レビュー・承認** → 品質管理部長が最終承認

### レビュー観点
- 内容の正確性・妥当性
- 文章の読みやすさ・わかりやすさ
- ブランドガイドとの整合性
- テンプレートの遵守
- 誤字脱字・文法

---

## 成果物別チェックリスト

### 提案書・営業資料
- [ ] クライアント名・案件名が正しいか
- [ ] 課題と提案の論理的なつながりがあるか
- [ ] 金額・数字に誤りがないか
- [ ] スケジュールが現実的か
- [ ] 誤字脱字がないか
- [ ] フォーマットが統一されているか

### ブログ・コンテンツ
- [ ] ターゲット読者に適したトーンか
- [ ] SEOキーワードが適切に含まれているか
- [ ] 見出し構成が論理的か
- [ ] CTAが明確か
- [ ] ファクトチェック済みか
- [ ] 画像・図表の品質は十分か

### SNS投稿
- [ ] ブランドトーンに沿っているか
- [ ] 文字数制限を守っているか
- [ ] ハッシュタグは適切か
- [ ] リンク先は正しいか
- [ ] 投稿タイミングは適切か

### 請求書・帳票
- [ ] 金額の計算が正しいか
- [ ] 振込先情報が正確か
- [ ] 発行日・支払期限が正しいか
- [ ] インボイス番号が記載されているか
- [ ] 消費税の計算が正しいか

---

## 品質メトリクス

### 測定項目
- レビューでの指摘件数（重大/軽微）
- 修正回数（初回承認率の追跡）
- 納期遵守率
- クライアントからのフィードバック

### 目標
- 重大な指摘: 0件/月
- 初回承認率: 80%以上
- 納期遵守率: 95%以上
