# 財務報告ガイドライン

## 目的
島村楽器株式会社の財務報告における正確性・一貫性・適時性を確保するための基準を定める。

## 適用範囲
財務経理部が作成する全ての財務報告書、および他部門が財務データを含む資料を作成する場合に適用。

## 基本原則
1. **正確性** - 数値は必ず元データと照合する
2. **一貫性** - 会計方針・表記方法を統一する
3. **適時性** - 期限を厳守する
4. **透明性** - 前提条件・算出根拠を明示する

## 会計基準
- 日本基準（J-GAAP）に準拠
- 重要な会計方針の変更は注記で開示

## 数値表記ルール
| 項目 | ルール | 例 |
|---|---|---|
| 金額単位 | 千円単位（億円は併記可） | 1,234,567千円（約12.3億円） |
| 桁区切り | 3桁ごとにカンマ | 1,234,567 |
| マイナス表記 | △（三角）を使用 | △1,234千円 |
| 比率 | 小数点第1位まで | 12.3% |
| 増減率 | 前年同期比で表記 | 前年同期比 +5.2% |

## 月次決算スケジュール
| 営業日 | タスク | 担当 |
|---|---|---|
| 翌月1日 | 仕訳締め切り | 経理担当 |
| 翌月3営業日 | 試算表作成 | 経理担当 |
| 翌月4営業日 | 差異分析 | CFO |
| 翌月5営業日 | 月次決算報告 | CFO → 統括部長 |

## 必須レポート項目
### 月次決算報告書
1. 損益計算書（P/L）- 月次・累計・予算比・前年比
2. 貸借対照表（B/S）- 月末残高
3. キャッシュフロー計算書（CF）- 月次・累計
4. 予算実績対比表 - 差異分析コメント付き
5. 主要KPI - 売上高、粗利率、営業利益率、EBITDA

### 四半期レビュー
- 上記に加え、セグメント別分析（楽器販売/音楽教室/その他）
- 通期業績見通しの更新

## 承認フロー
1. 経理担当が作成
2. CFOがレビュー・承認
3. 品質レビュー部が整合性チェック
4. 統括部長に報告

## 保管ルール
- 財務報告書は7年間保管
- 元データ・仕訳帳は10年間保管
